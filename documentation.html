Welcome to GroupForge Documentation. This guide will help you understand every feature from basic uploads to advanced multi-sheet exports.

Overview

GroupForge is a web-based tool designed to split CSV or Excel member lists into balanced groups. Whether you are organizing students, managing event attendees, or creating team assignments, GroupForge streamlines the process.

Getting Started

Follow these steps to create your first groups:

  1. Upload your CSV or Excel file by clicking the upload zone or dragging and dropping
  2. Select which columns you want to include in the output
  3. Choose between Single Grouping or Multiple Groupings mode
  4. Enter your desired group size or sizes
  5. Click Generate and Download Excel

File Format Requirements

GroupForge accepts the following file formats:

  • CSV - Comma-separated values with header row
  • Excel - .xlsx or .xls files with header row

Your file must include a header row as the first row containing column names. Example:

Name,Index Number,Department,Email
Emma Thompson,20240001,Computer Science,emma@university.edu
David Chen,20240002,Computer Science,david@university.edu
Any column can be used to identify members. The tool preserves all selected columns in the final output.

Data Import

Uploading your data is straightforward:

  • Click the upload zone and select your file from your computer
  • Drag and drop your file directly onto the upload zone
  • Supported formats include CSV, XLSX, and XLS

Once uploaded, GroupForge automatically detects column headers and displays a preview of your data with the first 10 rows.

Column Selection

You can choose which columns to include in your groups:

  • All columns are selected by default after upload
  • Uncheck any columns you want to exclude from the output
  • Use the Select All button to quickly toggle all columns
  • The preview table shows the first 10 rows with your selected columns
Removing unnecessary columns makes your output cleaner and easier to read.

Single Grouping Mode

Create groups with one consistent size across all members:

  • Enter the number of members per group
  • The interface shows real-time group count as you type
  • The last group may contain fewer members if the total is not divisible by the group size
  • Output is a single Excel sheet containing all groups
Example: 30 members with 5 per group = 6 groups

Multiple Groupings Mode

Create multiple group configurations within a single Excel file:

  • Add multiple group sizes such as 3, 5, and 10 members per group
  • Each configuration generates a separate sheet in the output file
  • Customize sheet names for each configuration to keep things organized
  • Ideal for comparing different grouping strategies side by side
Example Output Structure:
Sheet 1: Groups of 3
Sheet 2: Groups of 5
Sheet 3: Groups of 10

Export Options

GroupForge exports to Excel format with the following characteristics:

  • Single Mode produces one sheet named automatically
  • Multiple Mode produces multiple sheets with custom or auto-generated names
  • Each sheet displays groups with headers and member data
  • Blank rows separate groups for improved readability
Excel sheet names have a 31-character limit. Custom names exceeding this limit are automatically trimmed.

Frequently Asked Questions

What file size can I upload?

GroupForge handles files up to 200MB in the browser. For CSV files, this typically means hundreds of thousands of rows.

Does my data leave my computer?

No. All processing happens locally in your browser. Your data never leaves your computer, ensuring complete privacy and security.

Can I use GroupForge offline?

Yes. Once the page has loaded, GroupForge works without an internet connection.

What happens to the last group if it is incomplete?

The last group will contain the remaining members, even if the count is less than the specified group size.

Can I rename the output sheets?

Yes. In Multiple Groupings mode, each configuration includes a custom sheet name field.

Troubleshooting

File will not upload

Ensure your file is in CSV or Excel format and includes a header row with column names.

Preview shows unexpected characters

Save your CSV file with UTF-8 encoding. Excel files should be standard .xlsx format.

Groups are not displaying correctly

Verify that you selected the correct column for member identification. The tool groups entire rows based on the selected column.
